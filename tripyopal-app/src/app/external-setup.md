# Integración con APIs externas

## Clima
- Usa OpenWeather API para obtener clima en tiempo real.
- Requiere una API key en NEXT_PUBLIC_OPENWEATHER_API_KEY.

## Mapas
- Usa Google Maps JavaScript API para mostrar un mapa interactivo.
- Requiere una API key en NEXT_PUBLIC_GOOGLE_MAPS_API_KEY.

## Próximo paso
1. Crear cuenta en OpenWeather.
2. Crear cuenta en Google Cloud para Maps.
3. Agregar las keys a .env.local.
4. Conectar los servicios de weather.ts y maps.ts a los componentes UI.
